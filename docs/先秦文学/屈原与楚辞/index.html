屈原与楚辞

第一节 楚辞的产生与特点​

一、楚辞的名称与含义​

  1. “楚辞”本义为楚地的歌辞，是战国时期以屈原为代表的楚地诗人创作的一种新诗体。
  2. 西汉刘向辑录屈原、宋玉等人作品，编成《楚辞》一书，成为中国文学史上第一部浪漫主义诗歌总集。
  3. 楚辞与《诗经》并称“风骚”，共同奠定中国古典诗歌传统。

二、楚辞产生的文化背景​

  1. 楚地文化：楚国有独特的巫祭文化、神话传统与音乐体系，楚辞深受楚地民歌、巫歌影响。
  2. 中原文化影响：屈原熟习中原文化，将儒家理想与楚地浪漫传统相结合。
  3. 时代背景：战国末年楚国政治腐败、国势衰微，屈原的忧国忧民情怀催生了楚辞的创作。

三、楚辞的艺术特点​

  1. 句式灵活：突破《诗经》四言为主的句式，多用六七言，杂言相间，长短不拘。
  2. 语气词丰富：大量使用“兮”字，形成回环往复、一唱三叹的韵律效果。
  3. 浪漫主义精神：想象丰富，意象奇丽，充满神话色彩与主观抒情色彩。
  4. 地方色彩浓厚：大量运用楚地方言、名物、风俗、神话意象。
  5. 香草美人象征：以香草比喻高洁人格，以美人比喻理想君主或美好政治。

第二节 屈原的生平与创作​

一、屈原的生平​

  1. 屈原，名平，字原，战国末期楚国人，约生于公元前 340 年，卒于公元前 278 年。
  2. 曾任楚怀王左徒、三闾大夫，参与内政外交，主张联齐抗秦、革新政治。
  3. 因遭上官大夫靳尚、令尹子兰等人谗毁，被疏远流放。
  4. 顷襄王二十一年（前 278 ），秦将白起攻破郢都，屈原悲愤交加，自投汨罗江而死。

二、屈原的作品​

  1. 据《汉书·艺文志》记载，屈赋共二十五篇。
  2. 可确定为屈原所作的主要作品有：
    • 《离骚》：长篇抒情诗，屈原代表作。
    • 《九歌》：11 篇，祭神乐歌，包括《东皇太一》《云中君》《湘君》《湘夫人》《大司命》《少司命》《东君》《河伯》《山鬼》《国殇》《礼魂》。
    • 《天问》：通篇对天地自然、神话历史提出一百七十多个问题。
    • 《九章》：9 篇，多为屈原流放中抒情述志之作，包括《惜诵》《涉江》《哀郢》《抽思》《怀沙》《思美人》《惜往日》《橘颂》《悲回风》。
    • 《招魂》：一说为屈原所作，一说为宋玉所作。

第三节 《离骚》的思想与艺术​

一、《离骚》的内容​

  1. 自述身世与政治理想：叙述屈原出身贵族、志向高洁、辅佐楚王革新的经历。
  2. 抒发政治失意的悲愤：揭露奸佞谗毁、君王昏庸，表达忠而被谤的痛苦。
  3. 表现执着追求的精神：虽遭放逐，仍坚持理想，上下求索，九死不悔。

“路漫漫其修远兮，吾将上下而求索。” “亦余心之所善兮，虽九死其犹未悔。”

二、《离骚》的艺术特色​

  1. 宏伟的结构

    • 全诗 373 句，近 2500 字，是中国古代最长的抒情诗。
    • 以自述生平为主线，穿插抒情、议论、幻想，结构波澜壮阔。

  2. 香草美人象征

    • 以“香草”比喻高洁品德，以“美人”比喻理想君主或政治理想。
    • 开创了中国古典诗歌“香草美人”的象征传统。

  3. 浓郁的浪漫主义色彩

    • 大量运用神话传说、想象夸张，如驾龙乘凤、神游天地、叩帝阍、求佚女。
    • 现实与幻境交织，情感激越奔放。

  4. 鲜明的人格精神

    • 塑造了一个坚守理想、爱国忧民、上下求索的抒情主人公形象。
    • 对后世文人的人格追求产生深远影响。

第四节 屈原其他作品与宋玉​

一、《九歌》​

  1. 原是楚地民间祭神乐歌，经屈原加工润色而成。
  2. 内容多写人神恋爱、祭祀场景，情感缠绵悱恻，意境优美。
  3. 代表篇目：《湘君》《湘夫人》《山鬼》《国殇》等。

《国殇》祭祀阵亡将士，悲壮激越，是《九歌》中风格最独特的一篇。

二、《天问》​

  1. 全诗以问句构成，对宇宙生成、自然现象、神话传说、历史兴亡提出连串质疑。
  2. 表现了屈原大胆的怀疑精神、探索精神和渊博的学识。
  3. 是中国古代思想史上极具特色的哲理诗。

三、《九章》​

  1. 多为屈原流放期间的作品，直抒胸臆，现实性较强。
  2. 《哀郢》抒发国破家亡之痛，《涉江》写流放历程，《橘颂》以橘自喻高洁品格。

四、宋玉及其他楚辞作家​

  1. 宋玉：战国末期楚辞作家，相传为屈原弟子。

    • 代表作《九辩》，以悲秋为主题，抒发怀才不遇之情。
    • 开创了“悲秋”主题，对后世文学影响深远。

  2. 唐勒、景差：与宋玉同时的楚辞作家，作品多已散佚。

第五节 楚辞的历史地位与影响​

一、文学史上的地位​

  1. 楚辞是中国第一部浪漫主义诗歌总集，开创了中国文学的浪漫主义传统。
  2. 与《诗经》并称“风骚”，是中国古典诗歌的两大源头。
  3. 屈原是中国文学史上第一位伟大诗人，开创了“诗人”这一文学主体。

二、对后世文学的影响​

  1. 直接影响汉代辞赋：贾谊、枚乘、司马相如等人皆深受楚辞影响，汉代赋体文学由此兴起。
  2. 影响后世诗歌：李白、李贺、李商隐等浪漫主义诗人继承楚辞的想象与抒情传统。
  3. 影响戏曲小说：楚辞中的神话意象、人物原型不断被后世戏曲、小说吸收。

三、文化精神影响​

  1. 屈原的爱国精神、高洁人格与执着追求，成为后世文人的精神典范。
  2. 端午节纪念屈原、龙舟竞渡等民俗，体现了楚辞文化在民间的深远影响。

司马迁《史记·屈原列传》评曰：“其志洁，故其称物芳；其行廉，故死而不容。”
