杜甫

第一节 杜甫的生平及创作经历​

一、杜甫家世​

杜甫（712—770），字子美，生于巩县（今河南巩义）。十三世祖杜预是西晋名将兼学者，曾注《左传》。祖父杜审言是初唐著名诗人，官至膳部员外郎。父亲杜闲，曾为兖州司马、奉天县令。自称“杜陵野老”“杜陵布衣”。

二、杜甫生平与创作经历​

  1. 第一阶段，读书壮游时期（35岁前）。
  2. 第二阶段，困守长安时期（35岁至44岁）。
  3. 第三阶段，为官、流亡时期（45岁至48岁）。
  4. 第四阶段，漂泊西南时期（49岁至59岁去世）。

绝笔诗：“战血流依旧，军声动至今。”——《风疾舟中伏枕抒怀奉赠湖南亲友三十六韵》

三、诗史的性质​

“诗史”之称，最早见于孟棨《本事诗》：“杜逢禄山之乱，流离陇蜀，笔陈于诗，推见至隐，殆无遗事，故当时号为诗史。”后宋祁在《新唐书·杜甫传》中亦称：“甫又善陈时事，律切精深，至千言不少衰，世号诗史。”后遂以“诗史”称杜甫的纪实性作品。

我们称杜诗为诗史，不仅仅是因为它记录了某个事件、某个历史过程，而是有其他更重要的意义在。这个意义在于，历史记录往往是不带感情的、客观冷静的记录；而杜诗中的记录是倾诉了杜甫全部感情的、心灵的记录。

第二节 杜甫诗歌的艺术成就​

一、众体兼长​

  1. 一是各类体裁都擅长。
  2. 二是博采古今作家之长，兼备各类风格。

二、律诗的开拓与卓越造诣​

  1. 首先，杜甫对律诗题材的开拓。

    杜甫充分发掘了这一诗歌形式所蕴涵的可能性，使七律成为一种既工丽严整，又开阖动荡，具有独特艺术表现力的诗型。杜甫还使用七律表现现实重大题材，加入了较多抒情与议论，大大拓展了律诗的表现空间。

    《蜀相》：丞相祠堂何处寻，锦官城外柏森森。映阶碧草自春色，隔叶黄鹂空好音。三顾频烦天下计，两朝开济老臣心。出师未捷身先死，长使英雄泪满襟。

  2. 其次，杜甫还用多首律诗围绕一个主题展开抒写。以组诗形式写律诗，为杜甫所独擅。如《诸将五首》《秋兴八首》等。

  3. 再次，杜甫对律诗诗境的开拓。

    杜甫律诗曲尽其变，合律而不受声律束缚，对仗工整而不觉其迹，从而营构出了浑然一体的诗境。

    《登高》：风急天高猿啸哀，渚清沙白鸟飞回。无边落木萧萧下，不尽长江滚滚来。万里悲秋常作客，百年多病独登台。艰难苦恨繁霜鬓，潦倒新停浊酒杯。

  4. 最后，是杜甫对律诗艺术技巧的开拓。

    一方面，钻研诗律，同时又讲求自然天成。另一方面，炼字炼句的成功。

    《闻官军收河南河北》：剑外忽传收蓟北，初闻涕泪满衣裳。却看妻子愁何在，漫卷诗书喜欲狂。白日放歌须纵酒，青春作伴好还乡。即从巴峡穿巫峡，便下襄阳向洛阳。

三、古体诗的开拓与创新​

杜甫的古体诗创作分为两类：

  • 一类是用五言古体写成的自叙性叙事长篇，其中以《自京赴奉先县咏怀五百字》《北征》最为有名；
  • 另一类是以《兵车行》《丽人行》“三吏”“三别”为代表的乐府诗。

杜甫的古体诗的特点：

  1. 首先，杜甫的古体诗善于揭示人物复杂的内心活动，如《新婚别》。
  2. 其次，杜甫常把自己的主观爱憎融注入古体诗中。
  3. 再次，善于刻画典型画面，来对现实进行高度的艺术概括。

四、沉郁顿挫的风格​

  • “沉郁顿挫”一词出自杜甫的《进雕赋表》。“沉郁”主要是指感情深沉苍凉、境界开阔壮大；“顿挫”则指语言刚健、音调铿锵和章法多变。沉郁顿挫主要概括了杜诗在思想内容方面忧愤深广，而在表达上波澜曲折的特点。
  • 他的诗，蕴含着一种厚积的感情力量，每欲喷薄而出时，他的仁者之心、他的儒家涵养便把这喷薄欲出的悲怆抑制住了，使它变得缓慢、深沉，变得低回起伏。
  • 在语言锤炼方面也体现了沉郁顿挫的风格。杜诗用字下语，安排句式，务使声韵铿锵，抑扬缓急，顿挫有致。

第三节 杜甫对后世的影响​

  • 首先，杜甫精湛的诗歌艺术泽被后世诸多诗人。到了宋代，杜诗在长期接受过程中得到普遍认可，成为宋人作诗效法的最高典范。
  • 其次，杜甫忠君爱国、仁民爱物的思想对后世也有巨大的影响。
