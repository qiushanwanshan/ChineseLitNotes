李清照

第一节 李清照的生平及个性​

一、李清照的生平​

李清照（1084—1155？），号易安居士，济南章丘人。流传至今的词作计四十馀首，后人辑为《漱玉集》。父李格非“以文章受知于苏轼”，为苏门“后四学士”之一。母亲为王拱辰孙女，大家闺秀。丈夫赵明诚为金石考据家。

  • 苏门后四学士：李格非、廖正一、李禧、董荣
  • 苏门四学士：黄庭坚、秦观、晁补之、张耒

李清照文学成就和地位高的原因：

  • 首先，与词这个文体的特质有关。宋词具有浓厚的女性文学特征，词柔婉低约的审美特征，与古代女子的群体特征是相吻合的。

  • 其次，和李清照的家庭出身、人生经历以及因此而形成的个性特征有关。建中靖国元年（1101年），18岁的李清照，嫁给了比她大三岁的丈夫赵明诚。受到党争影响，俩人曾回到山东老家，共同生活了十年。靖康之难发生，李清照44岁这一年，跟着丈夫南渡，到了南京。两年后，赵明诚中暑得病去世。46岁以后的李清照，一直在颠沛流离中度过，最后自己一个人孤苦无依地在南方去世。

二、李清照的个性：爽直→倔强自信、自立自强​

个性形成原因：

  • 首先，与她少女时期自由宽松的家庭教育有关；

    《如梦令》：常记溪亭日暮，沉醉不知归路，兴尽晚回舟，误入藕花深处。争渡，争渡，惊起一滩鸥鹭。

    《如梦令》：昨夜雨疏风骤，浓睡不消残酒。试问卷帘人，却道海棠依旧。知否，知否？应是绿肥红瘦。

  • 其次，与她美满的婚姻有关，遇到了门当户对又情投意合的良人。

李清照叛逆个性的五种表现：

  1. 敢于讽刺公公，以下犯上。“炙手可热心可寒”

  2. 始终关心国家大事，不愿守在闺中。

    《夏日绝句》：“生当作人杰，死亦为鬼雄。至今思项羽，不敢过江东。”

  3. 在《词论》中敢于批评世人眼中的名流。

    • 评柳永：“虽协音律，而词语尘下”；
    • 评欧阳修和苏轼：“不协音律”，是“句读不茸之诗”；
    • 评王安石：“不可读也”；
    • 评晏几道：“苦无铺叙”；
    • 评贺铸：“苦少重典”；
    • 评秦观：“专主情致，而少故实”；
    • 评黄庭坚：“尚故实而多疵病”。

    提出的核心观点：“词别是一家”，指出词作为一种独立的文学体裁的特点及创作标准。即，要“协律”，要“可歌”。

  4. 晚年的再嫁与离异（张汝舟）。

  5. 文学创作独辟蹊径，敢于流露真情实感。

第二节 李清照前期词作​

前期词多写闺情、闲游与夫妇暌违之思，情感总体上较南渡后更为明丽深婉；代表作法详见下节所举《一剪梅》《醉花阴》等。

第三节 李清照南渡以后的词作​

  • 李清照前期词爽朗明快，主要写闺中少女的生活情怀，婚姻的甜蜜，夫妻的深情以及别后对丈夫的思念。

  • 在南渡以前，李清照的词中，抒写的是一种生离的愁苦，悲伤中还包含着期盼，冷清中又有热烈的渴望。她的一言一行，都是为了引起丈夫的注意，指向团圆的那一时刻。

    《一剪梅》：红藕香残玉簟秋。轻解罗裳，独上兰舟。云中谁寄锦书来，雁字回时，月满西楼。/花自飘零水自流。一种相思，两处闲愁。此情无计可消除，才下眉头，却上心头。

    《醉花阴》：薄雾浓云愁永昼，瑞脑消金兽。佳节又重阳，玉枕纱厨，半夜凉初透。/东篱把酒黄昏后，有暗香盈袖。莫道不销魂，帘卷西风，人比黄花瘦。

  • 但南渡以后，则是一种死别的悲苦，是人生了无趣味的生不如死的煎熬，是过得一天是一天的彻底的绝望。

    《武陵春·春晚》：风住尘香花已尽，日晚倦梳头。物是人非事事休，欲语泪先流。/闻说双溪春尚好，也拟泛轻舟。只恐双溪舴艋舟，载不动许多愁。

    《声声慢》：寻寻觅觅，冷冷清清，凄凄惨惨戚戚。乍暖还寒时候，最难将息。三杯两盏淡酒，怎敌他、晚来风急？雁过也，正伤心，却是旧时相识。/满地黄花堆积。憔悴损，如今有谁堪摘？守着窗儿，独自怎生得黑？梧桐更兼细雨，到黄昏、点点滴滴。这次第，怎一个愁字了得！

第四节 李清照的文学成就​

  • 首先，作为一个女性词人，其词在描写心理和情感的活动方面有其特别的长处。她不仅善于捕捉那些细小而生动的形象来表达难以言传的感受，而且善于表现情感的微妙变化，在起伏回环的语脉中层层剖露复杂的心境。比如我们前面举例的《武陵春》《醉花阴》《一剪梅》。
  • 其次，在语言技巧上，是经过精心锤炼之后的浅易自然。
  • 最后是李清照在词论上的贡献。其《词论》，从本体论的角度，确立了词体独立的文学地位。
  • 易安体：宋代词人李清照，号为易安居士，故她的词被称为易安体。主要有三方面的特点：一是用通俗易懂的文学语言和明白晓畅的音律声调作词；二是融入家国兴亡的深悲剧痛，同时又不失婉约词的本色，具有凄婉悲怆的格调；三是倜傥有丈夫气。
