晚唐五代诗坛

第一节 李商隐​

一、甘露之变​

公元835年（唐太和九年），27岁的唐文宗不甘为宦官控制，和李训、郑注策划诛杀宦官，以夺回皇帝丧失的权力。11月21日，唐文宗以观露为名，将宦官头目仇士良骗至禁卫军的后院欲斩杀，被仇士良发觉，双方激烈战斗，结果李训等朝廷重要官员被宦官杀死，其家人也受到牵连而灭门，在这次事变后受株连被杀的一千多人。史称“甘露之变”。

二、晚唐诗歌三大题材：历史、自然、爱情​

  • 对历史的追怀是对现实的喟叹；
  • 对自然的眷念是对人世的疲倦；
  • 对爱情的追求是对心灵的抚慰。

三、李商隐​

李商隐其人与诗风

字义山，号玉溪生，又号樊南生。诗风凄艳浑融，却有着博大的气象和意境的完整性，这是由于：

  • 李商隐拥有自己的意象群。所用的意象在色调、气息、情意指向上有其一致性。
  • 李诗技法纯熟。声调的和谐、虚字的斡旋控驭，事典的巧妙组织，近体在形式上的整齐规范，都增加了诗脉的圆融畅适。
  • 情感的统一。那种孤独、飘零、惘然、无奈、寥落、伤感的情绪，浓郁而又深厚弥漫在许多诗中，使诗的各部分得以融合、贯通，成为浑然体。

李商隐对前人的承继

  • 李商隐与齐、梁诗歌

    • 同：李商隐诗歌中的爱情和绮艳题材比重很大，同时讲究词藻声律、对仗用典，这与齐梁诗无疑有渊源关系。
    • 异：齐、梁诗主要兴趣在描写闺阁楼榭与女子的容貌体态服饰，重声色而乏性情。李商隐的爱情诗，侧重于感情领域的表现，摆脱了以满足感官欲望为特征的庸俗情调，以其深情绵邈把这一题材的诗境推向高峰。

  • 李商隐与阮籍

    • 同：象征性，朦胧多义而不易索解。
    • 异：
      1. 阮：主理；李：主情。
      2. 阮：略形取神，虚化玄奥；李：“有声有色，有情有味”

  • 李商隐与李贺

    • 同：均走向幽奥隐微的境界。
    • 异：
      1. 在章法上：李贺“于章法每不大理会”，夹杂着生而未化的成分。李商隐：把幽奥隐微的情感，用律体的形式写出。精心结撰，才思绵密，既有沉郁之致，又精美妥贴。
      2. 在色彩感官上：李贺：个性极强，在失落中追求心理上的补偿，有很强的感官欲求。所写的物象，往往具有特别的硬度和锋芒。又多用颜色字，瑰丽炫目。李商隐：虽美艳而又较少给人色彩刺激，归于温润纯熟。李贺红、绿、青、紫四种颜色字使用的频率是李商隐的23倍，其中红、绿二色为3.3倍。可见一追求颜色刺激，一比较淡雅。

  • 李商隐与杜甫

    • 同：沉郁、浑融。
    • 异：杜甫偏外向，诗境与社会与自然直接沟通。李商隐转向内心，内在浩浩茫茫，无涯无际，扑朔迷离。

第二节 杜牧：最后的士族​

  • 杜牧，字牧之，号樊川居士，因在家中排行十三被称为“杜十三”，唐京兆万年人。其远祖杜预为西晋著名的政治家和学者，曾祖杜希望为玄宗时戍守边塞的名将，爱好文学。祖父杜佑是中唐著名的政治家、史学家，官至宰相仍手不释卷，所撰《通典》二百卷，是关于中国古代典章制度的重要著作。杜牧的一生，历经唐王朝德、顺、宪、穆、敬、文、武、宣八帝。这是唐王朝意欲中兴最终却梦想破灭走向全面溃退的时期。号称“杜紫薇”，后世称他“杜樊川”。他有《杜樊川集》，存诗200余首。

  • 代表：咏史诗

    杜牧《题桃花夫人庙》：细腰宫里露桃新，默默无言度几春。至竟息亡缘底事，可怜金谷坠楼人。

    杜牧《题乌江亭》：胜败兵家事不期，包羞忍耻是男儿。江东子弟多才俊，卷土重来未可知。

    杜牧《赤壁》：折戟沉沙铁未销，自将磨洗认前朝。东风不与周郎便，铜雀春深锁二乔。

    在咏史诗中阐发议论，表达自己对历史事件的反思和见解，这是杜牧咏史诗的独到之处。这种带有反思和批判的理性精神，与此前重在抒发感慨的咏史怀古之作有了区别，直接影响了宋代咏史诗的创作。

  • 风格：俊爽豪迈又带柔美绮情

    杜牧《遣怀》：落拓江湖载酒行，楚腰纤细掌中轻。十年一觉扬州梦，赢得青楼薄幸名。

    杜牧《赠别二首》其一：娉娉袅袅十三馀，豆蔻梢头二月初。春风十里扬州路，卷上珠帘总不如。

    杜牧《将赴吴兴登乐游原》：清时有味是无能，闲爱孤云静爱僧。欲把一麾江海去，乐游原上望昭陵。

    杜牧《山行》：远上寒山石径斜，白云深处有人家。停车坐爱枫林晚，霜叶红于二月花。

    杜牧《长安秋望》：楼倚霜树外，镜天无一毫。南山与秋色，气势两相高。

第三节 晚唐五代的其他诗人​

一、温庭筠​

  • 字飞卿，太原祁人，时号“温八叉”，人称温方城、温助教。诗与李商隐合称“温李”。

  • 以女性为题材的诗歌在温诗中所占比重较大。

  • 温庭筠的诗体物细腻，笔墨精致，情意蕴藉，充满诗情画意。

    《商山早行》：“鸡声茅店月，人迹板桥霜。”

二、郑谷与晚唐五代苦吟诗人​

  • 郑谷的诗，受到晚唐没落的时代气息的影响，带有悲凉凄清的情调。
  • 郑谷作诗讲究字句，锻炼刻苦，其“一字师”的典故颇能道出他在诗歌创作上的孜孜以求。作诗苦吟不辍。同时，他也受到白居易浅近诗风的影响，形成浅显易懂的风格。
  • 晚唐五代时期，诗坛上有一批以苦吟而著称的诗人，继承贾岛姚合琢字炼句、刻苦作诗的传统，尤其讲究律诗的对仗。无论字句还是诗歌气象，都和贾岛姚合非常相似。

三、司空图、韦庄与乱世诗人​

  • 司空图，字表圣，河中虞乡人。
  • 韦庄，字端己，京兆万年人。
