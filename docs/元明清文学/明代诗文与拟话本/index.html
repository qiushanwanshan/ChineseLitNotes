明代诗文与拟话本

第一节 明代诗文流派​

一、明初诗文​

  1. 宋濂、刘基、高启：明初文坛代表，诗文多学唐宋，风格浑厚。
  2. 台阁体：明成祖至成化年间，以三杨（杨士奇、杨荣、杨溥）为代表，诗文雍容典雅，歌功颂德，缺乏生气。

二、茶陵派​

  1. 茶陵派：成化至弘治年间，以李东阳为首，成员有谢铎、张泰、邵宝等。因李东阳为湖南茶陵人而得名。
  2. 主张纠正台阁体冗弱冗沓之风，强调诗文的法度和音律，追求典雅浑厚的风格。
  3. 重视诗歌的声律之美，对前后七子的复古运动有一定影响。
  4. 虽未完全摆脱台阁体影响，但在明代诗文发展中起到承前启后的作用。

三、前后七子与复古运动​

  1. 前七子：以李梦阳、何景明为代表，活动于弘治、正德年间。主张“文必秦汉，诗必盛唐”，反对台阁体，强调复古。
  2. 后七子：以李攀龙、王世贞为代表，活动于嘉靖年间。继续提倡复古，影响更大。
  3. 复古主张的得失：
    • 积极作用：冲击台阁体，重视文学的艺术性和传统价值。
    • 消极影响：模拟因袭，缺乏创新，造成“文必秦汉，诗必盛唐”的僵化风气。

四、唐宋派与归有光​

  1. 唐宋派：反对前后七子的拟古主义，主张学习唐宋古文，强调文以明道，重视自然真情。
  2. 代表作家：归有光、唐顺之、王慎中、茅坤等。
  3. 归有光：
    • 字熙甫，号震川，昆山人。
    • 散文清新自然，善于写家庭琐事和日常亲情。
    • 代表作《项脊轩志》《先妣事略》《寒花葬志》等，以细节动人，感情真挚。

五、公安派与竟陵派​

  1. 公安派：以袁宗道、袁宏道、袁中道三兄弟为代表，湖北公安人。
    • 主张“独抒性灵，不拘格套”，反对复古模拟。
    • 强调文学应表现真实情感和个性，语言通俗自然。
    • 袁宏道散文小品《虎丘记》《满井游记》等影响较大。
  2. 竟陵派：以钟惺、谭元春为代表，湖北竟陵人。
    • 继承公安派性灵说，但追求“幽深孤峭”的风格，语言趋于艰涩。

六、明末诗文​

  1. 张岱：明末小品文代表，代表作《陶庵梦忆》《西湖梦寻》，文笔清丽，寄托故国之思。
  2. 陈子龙、夏完淳：明末抗清诗人，诗风悲壮沉郁，体现民族气节。
  3. 钱谦益、吴伟业：由明入清，诗文各有特色，吴伟业“梅村体”歌行尤负盛名。

第二节 明代拟话本​

一、拟话本的概念​

  1. 拟话本是明代文人模仿宋元话本形式创作的短篇白话小说。
  2. 与话本不同，拟话本不是民间艺人讲演记录，而是文人书面创作。
  3. 代表作为冯梦龙“三言”和凌濛初“二拍”。

二、冯梦龙与“三言”​

  1. 冯梦龙（1574–1646）：字犹龙，号墨憨斋主人，长洲人。明代著名文学家、戏曲家。
  2. “三言”：
    • 《喻世明言》（又名《古今小说》）
    • 《警世通言》
    • 《醒世恒言》
  3. 共收短篇小说约 120 篇，多取材于宋元旧篇、历史故事和民间传说，经冯梦龙加工改写。
  4. 主题广泛：爱情婚姻、公案侠义、世态人情、忠孝节义等。
  5. 名篇如《杜十娘怒沉百宝箱》《卖油郎独占花魁》《蒋兴哥重会珍珠衫》等。

三、凌濛初与“二拍”​

  1. 凌濛初（1580–1644）：字玄房，号初成，别号即空观主人，乌程人。
  2. “二拍”：
    • 《初刻拍案惊奇》
    • 《二刻拍案惊奇》
  3. 共 78 篇，多为凌濛初独创，较少改编旧篇。
  4. 内容多写商人、市民生活，反映明代社会变迁和价值观变化。

四、拟话本的艺术特色​

  1. 白话短篇小说形式成熟，结构完整，情节曲折。
  2. 人物多为市民、商人、妓女、手工业者，贴近市井生活。
  3. 语言通俗生动，保留话本的“入话”“正话”“篇尾诗”等体制。
  4. 对清代《聊斋志异》《儒林外史》《红楼梦》等小说创作产生影响。

五、历史意义​

  1. 拟话本标志着中国白话短篇小说的成熟。
  2. 三言二拍保存了大量明代社会史料，具有文学和文化研究价值。
  3. 其市民意识、人性描写、婚姻观念等，对后世小说产生深远影响。
