元杂剧与关汉卿

第一节 元杂剧的体制与特征​

一、元杂剧的基本体制​

  1. 结构：通常一本四折，外加一个或多个楔子。一折相当于现代戏剧的一幕，由同一宫调下的若干曲牌组成。
  2. 角色：主要分为末（男角）、旦（女角）、净（丑角或反面人物）、杂（其他配角）等。
  3. 表演形式：由唱、念、做、打组成，以唱为主。一本戏中通常由一个主要角色独唱到底（正末或正旦主唱）。
  4. 音乐：每折使用同一宫调的若干曲牌，形成套曲。常见的宫调有仙吕、南吕、正宫、双调等。
  5. 宾白：剧中人物对话，多用口语，推动情节、塑造人物。

二、元杂剧的分类​

  1. 历史剧：如《单刀会》《汉宫秋》《赵氏孤儿》。
  2. 爱情婚姻剧：如《西厢记》《墙头马上》。
  3. 公案剧：如《窦娥冤》《陈州粜米》。
  4. 神仙道化剧：如《黄粱梦》《任风子》。
  5. 水浒剧：如《李逵负荆》《燕青博鱼》。

三、元杂剧的艺术成就​

  1. 剧情紧凑，冲突集中，善于通过戏剧行动展现人物性格。
  2. 曲词兼具叙事性与抒情性，语言富有表现力。
  3. 角色类型化鲜明，正旦、正末、净等各行当分工明确。
  4. 题材广泛，反映社会现实，具有强烈的批判性和人民性。

第二节 关汉卿及其创作​

一、关汉卿的生平与地位​

  1. 关汉卿，号已斋叟，约生于金末元初，大都（今北京）人。元代杂剧奠基人，被后世尊为“曲圣”。
  2. 贾仲明《录鬼簿续编》称其为“驱梨园领袖，总编修师首，捻杂剧班头”。
  3. 一生创作杂剧约六十余种，现存十八种，代表作有《窦娥冤》《救风尘》《望江亭》《单刀会》《拜月亭》等。

二、《窦娥冤》分析​

  1. 剧情梗概：

    • 窦娥自幼丧母，父亲窦天章因贫困将她卖给蔡婆为童养媳。婚后不久丈夫去世，婆媳相依为命。流氓张驴儿父子图谋霸占婆媳，张驴儿欲毒死蔡婆却误杀其父，反诬窦娥。贪官桃杌草菅人命，窦娥被判处死刑。临刑前发下三桩誓愿：血溅白练、六月飞雪、亢旱三年，全部应验。三年后窦天章任廉访使，为女儿昭雪。

  2. 主题思想：

    • 揭露元代吏治黑暗、司法腐败、社会不公。
    • 歌颂窦娥善良、孝顺、坚贞不屈的品格。
    • 体现下层人民对正义的呼唤和对邪恶势力的反抗。

  3. 人物形象：

    • 窦娥：性格刚烈、正直善良，从忍辱负重到激烈反抗，是中国古代悲剧女性形象的典范。
    • 桃杌：贪官污吏的代表，象征元代的黑暗政治。
    • 张驴儿：市井流氓，体现社会道德的崩坏。

  4. 艺术特色：

    • 戏剧冲突激烈，情节跌宕，高潮迭起。
    • 浪漫主义手法（三桩誓愿的应验）增强悲剧感染力。
    • 曲词质朴悲愤，如“地也，你不分好歹何为地？天也，你错勘贤愚枉做天！”

三、关汉卿其他重要作品​

  1. 《救风尘》：写妓女赵盼儿机智救出被周舍虐待的宋引章，体现女性智慧与侠义。
  2. 《望江亭》：写谭记儿智斗权贵杨衙内，捍卫婚姻自主，喜剧色彩鲜明。
  3. 《单刀会》：写关羽单刀赴会，表现英雄气概，是历史剧代表作。
  4. 《拜月亭》：写王瑞兰与蒋世隆在战乱中的爱情故事，曲折感人。

四、关汉卿杂剧的艺术风格​

  1. 人物多为社会底层：妓女、寡妇、书生、小吏等。
  2. 语言本色当行，善用口语，符合人物身份。
  3. 戏剧冲突激烈，情节出人意料。
  4. 具有强烈的现实关怀和民本思想。

第三节 元曲四大家与其他重要作家​

一、元曲四大家​

“元曲四大家”指关汉卿、白朴、马致远、郑光祖四位元代杂剧作家，代表元代不同时期、不同流派杂剧创作的最高成就。明代何良俊《四友斋丛说》首提此说。

  1. 关汉卿：杂剧奠基人，本色派代表。代表作《窦娥冤》《救风尘》《单刀会》《拜月亭》。
  2. 白朴：字仁甫，号兰谷，出身金代官僚家庭，有遗民情绪。词采优美，情意绵长，属文采派。
    • 代表作《唐明皇秋夜梧桐雨》《裴少俊墙头马上》。
    • 《梧桐雨》取材白居易《长恨歌》，写唐明皇与杨贵妃的悲剧爱情。
  3. 马致远：号东篱，杂剧多写神仙道化、历史爱情与文人失意，语言清丽典丽。
    • 代表作《汉宫秋》《青衫泪》《荐福碑》《岳阳楼》。
    • 《汉宫秋》写汉元帝与王昭君的爱情悲剧，借古抒怀。
  4. 郑光祖：字德辉，平阳襄陵人，官至杭州路吏。爱情剧成就突出，语言典雅。
    • 代表作《迷青琐倩女离魂》《刍梅香骗翰林风月》《王粲登楼》。
    • 《倩女离魂》写倩女魂魄追随恋人，是对爱情忠贞不渝的经典描写。

二、元曲四大悲剧与四大爱情剧​

  1. 元曲四大悲剧：
    • 关汉卿《窦娥冤》
    • 白朴《梧桐雨》
    • 马致远《汉宫秋》
    • 纪君祥《赵氏孤儿》
  2. 元曲四大爱情剧：
    • 关汉卿《拜月亭》
    • 王实甫《西厢记》
    • 白朴《墙头马上》
    • 郑光祖《倩女离魂》

三、其他重要杂剧作家​

  1. 纪君祥：代表作《赵氏孤儿》，写春秋时期赵氏灭门与复仇，是著名历史悲剧，后被伏尔泰改编为《中国孤儿》。
  2. 康进之：代表作《李逵负荆》，是水浒戏中的优秀作品。
  3. 尚仲贤：代表作《柳毅传书》，写龙女与柳毅的爱情故事。
  4. 石君宝：代表作《秋胡戏妻》《曲江池》。
