《三国演义》与《水浒传》

第一节 《三国演义》​

一、作者与成书​

  1. 作者一般认为是罗贯中，名本，号湖海散人，元末明初人。
  2. 《三国演义》是中国第一部长篇章回体历史演义小说。
  3. 成书经历长期民间传说、史书记载（《三国志》及裴松之注）、话本（《全相三国志平话》）、戏曲（三国戏）的积累，最后由罗贯中综合加工写定。
  4. 现存最早刊本为明嘉靖壬午年（1522）刊本《三国志通俗演义》。

二、主要内容​

  1. 小说以东汉末年至西晋统一（约 184–280 年）近百年历史为背景。
  2. 以魏、蜀、吴三国政治、军事斗争为主线，描写黄巾起义、董卓之乱、群雄割据、三国鼎立、晋统一等历史事件。
  3. 重点刻画刘备、关羽、张飞、诸葛亮、曹操、孙权等历史人物。

三、思想倾向​

  1. 拥刘反曹：以蜀汉为正统，刘备集团代表仁政、忠义；曹操代表奸诈、暴政。
  2. 推崇忠义：关羽的义、诸葛亮的忠成为全书核心价值。
  3. 强调仁政：刘备“仁德”与曹操“奸雄”形成对比。
  4. 历史循环观：小说开篇即提出“天下大势，分久必合，合久必分”。

四、人物形象​

  1. 诸葛亮：智慧化身，鞠躬尽瘁，死而后已。其“空城计”“草船借箭”“七擒孟获”等故事家喻户晓。
  2. 关羽：忠义的象征，后被民间尊为“武圣”。
  3. 曹操：奸雄形象，雄才大略又多疑残忍，性格复杂。
  4. 刘备：仁君代表，善于用人，但带有一定的理想化色彩。

五、艺术成就​

  1. 宏大的历史叙事：时间跨度长，人物众多，事件复杂，结构严谨。
  2. “七实三虚”：大体依史实，细节多虚构，虚实结合。
  3. 战争描写出色：如赤壁之战、官渡之战，场面宏大，谋略迭出。
  4. 人物类型化鲜明：好人极好，坏人极坏，带有“脸谱化”倾向。
  5. 语言半文半白：雅俗共赏，具有历史感。

第二节 《水浒传》​

一、作者与成书​

  1. 作者一般认为是施耐庵，罗贯中可能参与整理修订。施耐庵生平资料较少，一说为元末明初人。
  2. 《水浒传》是中国第一部以农民起义为题材的长篇小说。
  3. 故事源于北宋末年宋江起义的历史事件，经民间传说、话本（《大宋宣和遗事》）、戏曲等长期积累，最终由文人写定。
  4. 版本复杂，主要有简本（百回）和繁本（百二十回、七十回等）之分。金圣叹评点七十回本影响最大。

二、主要内容​

  1. 描写北宋末年以宋江为首的 108 位好汉在梁山聚义、反抗官府压迫的故事。
  2. 全书可分“逼上梁山”“聚义发展”“受招安”“征辽征方腊”“悲剧结局”等部分。
  3. 核心情节包括林冲雪夜上梁山、武松打虎、智取生辰纲、三打祝家庄等。

三、主题思想​

  1. 官逼民反：揭示社会黑暗、吏治腐败，反映人民反抗的正义性。
  2. 忠义观念：梁山好汉以“忠义”为旗号，但忠义与反抗最终矛盾，导致招安悲剧。
  3. 替天行道：体现民间英雄理想与道德正义感。
  4. 招安悲剧：反映作者思想的矛盾与历史局限。

四、人物形象​

  1. 宋江：梁山领袖，绰号“及时雨”，重义气但忠于朝廷，最终主导招安，性格复杂。
  2. 武松：武艺高强，嫉恶如仇，景阳冈打虎、斗杀西门庆、血溅鸳鸯楼等故事突出其英雄形象。
  3. 林冲：由八十万禁军教头被逼上梁山，性格隐忍，最终奋起反抗。
  4. 李逵：粗鲁直率、忠诚勇猛，是草莽英雄的代表。
  5. 鲁智深：嫉恶如仇、豪爽仗义，体现佛门侠义精神。

五、艺术成就​

  1. 人物塑造个性化：108 将各具性格，避免单一化。
  2. 情节结构由连环列传式走向整体聚合：先分后合，层次分明。
  3. 白话小说语言成熟：口语化、生动活泼，是小说语言史上的里程碑。
  4. 英雄传奇模式：对后世侠义小说、公案小说影响深远。

六、历史影响​

  1. 《三国演义》开创历史演义小说传统，影响《东周列国志》《隋唐演义》等。
  2. 《水浒传》开创英雄传奇传统，影响《说岳全传》《杨家将演义》等。
  3. 两部作品共同奠定中国长篇小说的基础，对《西游记》《金瓶梅》及后世小说产生深远影响。
