王实甫与《西厢记》

第一节 王实甫生平与《西厢记》的成书​

一、王实甫简介​

  1. 王实甫，名德信，字实甫，大都（今北京）人，生卒年不详，主要活动于元成宗元贞、大德年间（约 1295–1307）。
  2. 一生创作杂剧十四种，今存《西厢记》《破窑记》《丽春堂》等。
  3. 《西厢记》是其代表作，被誉为“天下夺魁”之作。

二、《西厢记》的故事来源​

  1. 本事最早见于唐代元稹传奇小说《莺莺传》（又名《会真记》）。
  2. 宋代有《商调蝶恋花》鼓子词、赵令畤《蝶恋花鼓子词》等改编。
  3. 金代董解元《西厢记诸宫调》将悲剧结局改为团圆，奠定杂剧基础。
  4. 王实甫在董西厢基础上进一步加工，创作五本二十一折的杂剧巨制。

第二节 《西厢记》的剧情与人物​

一、剧情梗概​

  1. 崔相国去世，夫人郑氏携女儿莺莺扶柩回博陵安葬，暂居普救寺。
  2. 书生张珙（张君瑞）赴京赶考，路过普救寺，与莺莺一见钟情。
  3. 叛将孙飞虎兵围普救寺，欲劫莺莺。崔夫人许诺能退兵者以女妻之。张生请好友白马将军杜确解围。
  4. 事后崔夫人悔婚，只允许二人以兄妹相称。在红娘帮助下，张生与莺莺私订终身。
  5. 崔夫人发现后拷问红娘，红娘以理力争，夫人被迫允婚，但要求张生必须考取功名。
  6. 张生高中后归来，与莺莺终成眷属。

二、主要人物分析​

  1. 崔莺莺：相国千金，外表端庄矜持，内心热烈执着。既有贵族少女的教养，又有追求爱情的勇气。
  2. 张生（张君瑞）：痴情书生，才华横溢，痴情专一，但带有一定的软弱性和喜剧色彩。
  3. 红娘：全剧最光彩的人物。机智伶俐、勇敢仗义，成为撮合爱情的中心人物。后世“红娘”成为媒人的代名词。
  4. 崔夫人：封建家长代表，恪守门第观念，是爱情自由的主要阻力。

三、主题思想​

  1. 反对封建门第观念和包办婚姻，歌颂“愿普天下有情的都成了眷属”的爱情理想。
  2. 肯定青年男女自主追求爱情的权利，具有鲜明的反封建意义。
  3. 通过红娘等人物，赞美下层人物的智慧和正义感。

第三节 《西厢记》的艺术特色​

一、结构宏伟严谨​

  1. 全剧五本二十一折，突破元杂剧一本四折的惯例，规模宏大。
  2. 情节曲折，波澜起伏，张弛有度。
  3. 多处运用误会、巧合、悬念等戏剧手法。

二、曲词优美动人​

  1. 王实甫被誉为“花间美人”，曲词华丽典雅，富于诗情画意。
  2. 名句如“碧云天，黄花地，西风紧，北雁南飞。晓来谁染霜林醉？总是离人泪。”
  3. 曲词兼具抒情性与叙事性，情景交融。

三、人物塑造细腻​

  1. 心理描写深入，尤其善于表现莺莺内心矛盾。
  2. 人物语言个性化：莺莺含蓄，张生痴情，红娘泼辣直率。

四、历史影响​

  1. 《西厢记》对后世戏曲、小说影响深远，被誉为“杂剧之冠”。
  2. 明代李贽、金圣叹等评点家给予高度评价，金圣叹将其与《庄子》《离骚》《史记》《杜诗》《水浒传》并列，称为“第六才子书”。
  3. 其反封建主题在《牡丹亭》《红楼梦》等作品中得到进一步发展。
