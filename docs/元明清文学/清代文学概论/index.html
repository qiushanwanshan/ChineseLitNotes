清代文学概论

第一节 清代社会与文学背景​

一、清朝的建立与政治文化​

  1. 1644 年清军入关，建立清朝，定都北京。此后经过康熙、雍正、乾隆三朝，达到鼎盛，史称“康乾盛世”。
  2. 清朝加强思想控制，大兴文字狱，对知识分子进行严酷镇压。
  3. 同时清朝也推崇儒学，组织大规模文化工程，如编纂《四库全书》《康熙字典》《古今图书集成》等。
  4. 中叶以后，社会矛盾加剧，白莲教起义、太平天国运动等动摇清王朝统治。

二、清代文学的主要成就​

  1. 小说：长篇小说达到巅峰，《红楼梦》代表中国古代小说最高成就；《儒林外史》《聊斋志异》等亦成就卓著。
  2. 戏曲：昆曲传奇继续发展，洪昇《长生殿》、孔尚任《桃花扇》为清代戏曲双璧。
  3. 诗文：流派众多，神韵说、格调说、性灵说、肌理说等竞相争鸣。
  4. 词：清代词学复兴，纳兰性德、朱彝尊、陈维崧等大家辈出。
  5. 散文：桐城派成为清代主流散文派别，强调“义理、考据、辞章”。

三、清代文学的时代特征​

  1. 总结性与集大成：清代文学继承前代成就，在小说、戏曲、诗文各领域进行综合总结。
  2. 现实主义深化：小说戏曲更加关注社会现实，批判性增强。
  3. 学术化倾向：考据学兴盛，影响诗文创作，重学问、重法度。
  4. 流派林立：诗、词、文、戏曲理论高度发达，争鸣激烈。
  5. 雅俗交融：通俗小说与高雅诗文并行发展，相互影响。

第二节 清代小说的繁荣​

一、长篇小说的巅峰​

  1. 《红楼梦》：曹雪芹创作，代表中国古代小说艺术最高成就。
  2. 《儒林外史》：吴敬梓创作，讽刺科举制度和士林丑态，开讽刺小说先河。
  3. 《聊斋志异》：蒲松龄创作，文言短篇小说集，借鬼狐花妖写人间世相。

二、小说类型多样化​

  1. 世情小说：如《红楼梦》《金瓶梅》的延续。
  2. 讽刺小说：如《儒林外史》。
  3. 文言小说：如《聊斋志异》《阅微草堂笔记》。
  4. 侠义公案小说：如《三侠五义》《施公案》。
  5. 才子佳人小说：如《好逑传》《平山冷燕》。

三、清代小说的思想与艺术特征​

  1. 人物塑造的心理深度：如林黛玉、薛宝钗、贾宝玉等形象复杂立体。
  2. 叙事技巧的成熟：多线并进、伏笔照应、象征隐喻等手法高度发达。
  3. 社会批判意识：对科举、礼教、官场、家族制度等展开深刻批判。
  4. 语言艺术的高峰：白话小说语言达到精炼、生动、富有韵味的境界。

第三节 清代戏曲与诗文​

一、清代戏曲​

  1. 昆曲传奇的鼎盛：清初昆曲盛行，洪昇、孔尚任为代表。
  2. 花部兴起：乾隆以后，地方戏曲（花部）逐渐兴起，京剧最终形成。
  3. 戏曲理论：李渔《闲情偶寄》系统论述戏曲创作与表演。

二、清代诗歌​

  1. 清初遗民诗：顾炎武、黄宗羲、王夫之、屈大均等表现民族气节。
  2. 神韵说：王士禛主张“不着一字，尽得风流”。
  3. 格调说：沈德潜强调诗教，推崇盛唐格调。
  4. 性灵说：袁枚主张“诗者，人之性情也”。
  5. 肌理说：翁方纲主张以学问为诗，以考据入诗。

三、清代词与散文​

  1. 词：纳兰性德以小令凄婉著称；朱彝尊创浙西词派；陈维崧创阳羡词派；晚清张惠言创常州词派。
  2. 散文：桐城派方苞、刘大櫆、姚鼐主张“义理、考据、辞章”合一，影响深远。
