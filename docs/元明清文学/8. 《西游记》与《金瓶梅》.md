### 第一节 《西游记》

#### 一、作者与成书

1. 作者一般认为是吴承恩，字汝忠，号射阳山人，江苏淮安人，明代中叶人。
2. 《西游记》是中国第一部神魔小说，也是长篇浪漫主义小说的代表作。
3. 故事源于唐代玄奘西行取经的历史事件，经《大唐西域记》《大唐大慈恩寺三藏法师传》、宋代《大唐三藏取经诗话》、元代《西游记平话》及杂剧等长期积累，最终由吴承恩写定。
4. 明万历二十年（1592）世德堂本为最早刊本。

#### 二、主要内容

1. 全书共一百回，写孙悟空出世、大闹天宫，后被如来佛祖压在五行山下。
2. 唐僧受唐太宗之命西天取经，途中收孙悟空、猪八戒、沙僧为徒，白龙马为坐骑。
3. 师徒四人历经九九八十一难，战胜各路妖魔鬼怪，最终到达西天，取得真经，修成正果。

#### 三、主题思想

1. **反抗精神**：孙悟空大闹天宫象征对封建权威和神权秩序的挑战。
2. **修行与修心**：取经过程既是外在旅程，也是内在心性修炼，“心生种种魔生，心灭种种魔灭”。
3. **讽刺社会现实**：天宫、地府、西方佛国都存在腐败、昏庸、徇私等现象，影射人间社会。
4. **团队合作**：唐僧师徒性格互补，体现团结协作、各尽其能的精神。

#### 四、人物形象

1. **孙悟空**：全书核心人物。机智勇敢、嫉恶如仇、敢于反抗，是中国文学中最富生命力的英雄形象之一。
2. **唐僧**：慈悲为怀但迂腐固执，常因善恶不分而遭难，象征世俗化的高僧形象。
3. **猪八戒**：贪吃懒惰、好色自私，但本性善良，喜剧色彩浓厚，是人性化的形象。
4. **沙僧**：忠厚老实、任劳任怨，是团队中的稳定因素。

#### 五、艺术成就

1. **丰富的想象力**：上天入地、降妖伏魔，建构了瑰丽的神话世界。
2. **幽默讽刺风格**：以游戏之笔写严肃主题，讽刺与诙谐结合。
3. **人物塑造鲜明**：神、妖、人皆有性格，富有人情味。
4. **结构精巧**：以取经为主线，八十一难环环相扣，回目对仗工整。
5. **语言通俗生动**：融合口语、俚语、文言，具有鲜明的喜剧效果。

### 第二节 《金瓶梅》

#### 一、作者与成书

1. 作者署名“兰陵笑笑生”，真实身份不详，可能是山东籍文人。
2. 《金瓶梅》是中国第一部由文人独立创作的长篇白话世情小说。
3. 书名取自潘金莲、李瓶儿、庞春梅三位女性名字中的各一字。
4. 现存最早刊本为万历四十五年（1617）的《金瓶梅词话》。

#### 二、主要内容

1. 小说以《水浒传》中武松杀嫂故事为引子，写西门庆由发迹到败亡的过程。
2. 通过西门庆家庭内外的纠葛，展现明代中后期城市社会、官商勾结、家庭伦理、欲望膨胀等现实图景。
3. 潘金莲、李瓶儿、庞春梅、吴月娘、孟玉楼等女性人物构成复杂的家庭关系网络。

#### 三、主题思想

1. **暴露社会黑暗**：描写官场腐败、商人贿赂、司法不公，揭示晚明社会危机。
2. **批判纵欲主义**：以西门庆的纵欲亡身警示世人，具有明显的道德批判色彩。
3. **家庭伦理反思**：妻妾争斗、主仆倾轧，反映传统家庭结构的危机。
4. **女性命运的悲剧**：潘金莲等女性既是欲望和恶的体现者，也是男权社会的牺牲品。

#### 四、人物形象

1. **西门庆**：集商人、官僚、恶霸于一身，是晚明社会新兴势力的代表，最终被欲望吞噬。
2. **潘金莲**：聪明美貌、泼辣狠毒，是小说中最复杂的女性形象之一。
3. **李瓶儿**：温柔软弱，因情感依赖而悲剧收场。
4. **庞春梅**：由婢女升为夫人，性格刚烈，最终也走向毁灭。

#### 五、艺术成就

1. **由英雄传奇转向日常生活**：将小说从神魔、历史题材引向世态人情，开启世情小说传统。
2. **写实主义手法**：细致描写家庭琐事、市井生活、商业活动，具有社会风俗史价值。
3. **人物心理刻画**：对女性嫉妒、欲望、焦虑等心理有深入描写。
4. **结构由《水浒传》中一段故事扩展为百回巨制**：表现文人独立创作长篇小说的能力。
5. **语言生动**：运用山东方言、市井口语，鲜活传神。

#### 六、历史影响

1. 《金瓶梅》是世情小说的开山之作，直接影响《红楼梦》的创作。
2. 其家庭叙事、女性群像、细节写实等手法为后世小说提供了典范。
3. 因其大量性描写，历史上长期被列为禁书，但文学价值得到学界高度认可。
