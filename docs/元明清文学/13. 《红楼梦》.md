### 第一节 作者、成书与版本

#### 一、曹雪芹生平

1. **曹雪芹**（约 1715–1763），名霑，字梦阮，号雪芹，又号芹溪、芹圃。祖籍辽阳，生于南京，后迁居北京。
2. 出身清代内务府正白旗包衣世家，祖父曹寅曾任江宁织造，家世显赫，与康熙皇帝关系密切。
3. 雍正年间曹家被抄，曹雪芹由富贵坠入贫困，晚年居北京西郊，靠卖画和友人接济度日，创作《红楼梦》。
4. 生活经历使其对封建家族的兴衰、人情冷暖有深刻体悟。

#### 二、《红楼梦》成书与版本

1. 曹雪芹创作前八十回，后四十回一般认为由高鹗续补（一说程伟元、高鹗共同整理）。
2. 早期以抄本流传，称为“脂本”，因附有脂砚斋评语而得名。主要脂本有甲戌本、己卯本、庚辰本等。
3. 乾隆五十六年（1791），程伟元、高鹗以活字排版印刷一百二十回全本，称为“程甲本”，次年修订为“程乙本”。
4. 续书问题至今是红学争论焦点，一般认为后四十回在悲剧结局、人物命运等方面基本延续曹雪芹原意，但艺术水平有所下降。

### 第二节 思想内容

#### 一、主要情节

1. 小说以贾、史、王、薛四大家族为背景，以贾宝玉、林黛玉、薛宝钗的爱情婚姻悲剧为主线。
2. 描写贾府由盛转衰的过程，涉及日常生活、家族矛盾、礼教束缚、经济崩溃等多方面。
3. 最终以贾府败落、宝玉出家、黛玉之死、宝钗守寡等悲剧结局，展现封建末世图景。

#### 二、主题思想

1. **封建家族衰亡史**：通过贾府由盛转衰，揭示封建社会的腐朽与必然崩溃。
2. **爱情与婚姻悲剧**：宝黛爱情被封建礼教和家族利益摧毁，体现个性自由与封建秩序的矛盾。
3. **女性命运的悲剧**：大观园众多女子“千红一哭，万艳同悲”，控诉男权社会对女性才华与生命的压抑。
4. **人生虚幻与哲学思考**：通过“太虚幻境”“好了歌”等表达世事无常、人生如梦的感慨。
5. **对真善美的追求**：贾宝玉、林黛玉代表真挚情感与精神纯洁，与世俗功利形成对比。

#### 三、贾宝玉与“叛逆者”形象

1. 贾宝玉是封建贵族家庭的逆子，拒绝走仕途经济之路。
2. 他尊重女性，认为“女儿是水作的骨肉，男人是泥作的骨肉”，体现对女性的同情与尊重。
3. 他与林黛玉建立在共同思想基础上的爱情，是对封建婚姻制度的反抗。
4. 最终他选择出家，是对世俗社会的彻底决裂。

### 第三节 人物形象

#### 一、贾宝玉

1. 性格核心：多情、敏感、叛逆、追求精神自由。
2. 与黛玉志同道合，与宝钗思想相异。
3. 是作者理想人格与现实冲突的集中体现。

#### 二、林黛玉

1. 出身书香门第，寄居贾府，体弱多病，才华横溢。
2. 性格敏感、孤高、真诚，是封建礼教压迫下的悲剧女性。
3. 与宝玉有共同的叛逆思想，爱情真挚深沉。
4. 最终焚稿断痴情，泪尽而亡，体现“木石前盟”的悲剧宿命。

#### 三、薛宝钗

1. 出身皇商之家，容貌端庄，才德兼备，深受封建家长喜爱。
2. 性格稳重、理智、善于处世，代表封建淑女的典范。
3. 与宝玉成婚但缺乏精神共鸣，最终独守空房，是“金玉良缘”的悲剧。

#### 四、其他重要人物

1. **王熙凤**：精明强干、心狠手辣，是贾府实际管理者，也是封建家族腐败的化身。
2. **贾母**：贾府最高权威，仁慈但维护封建秩序。
3. **贾政**：封建正统家长代表，严厉而迂腐。
4. **晴雯、袭人**：丫鬟群像中的代表，体现不同性格与命运。
5. **史湘云、探春、妙玉、迎春、惜春**等：大观园女性群像，各有悲剧。

### 第四节 艺术成就

#### 一、人物塑造的巅峰

1. 全书塑造了数百个有血有肉的人物，主要人物性格复杂、立体，避免简单善恶二分。
2. 善于通过日常细节、对话、心理活动刻画人物。
3. 人物关系错综复杂，相互映照。

#### 二、网状叙事结构

1. 以贾府为中心，多线并进，主次分明。
2. 伏笔照应严密，如“金陵十二钗”判词预示人物命运。
3. 宏大结构却能细致入微，史诗性与日常性统一。

#### 三、语言艺术

1. 白话小说语言达到高度成熟，兼具口语的生动与文言的精炼。
2. 人物语言高度个性化：黛玉尖刻机敏，宝钗稳重圆融，凤姐泼辣爽利。
3. 诗词曲赋与叙事融合，如大观园诗社、判词、灯谜等皆有深意。

#### 四、象征与隐喻

1. **“太虚幻境”**：预示全书人物命运，带有哲学与宗教色彩。
2. **“通灵宝玉”**：象征宝玉的“顽石”本性与世俗使命的矛盾。
3. **“大观园”**：理想世界的象征，最终随贾府衰败而幻灭。
4. **“好了歌”与注**：概括全书虚无主题与世俗批判。

#### 五、现实主义与浪漫主义结合

1. 日常生活描写极为真实，被誉为“封建社会的百科全书”。
2. 神话框架（木石前盟、金玉良缘）赋予作品浪漫色彩和悲剧宿命感。

### 第五节 历史地位与影响

#### 一、文学地位

1. 《红楼梦》代表中国古代长篇小说的最高成就，被称为“中国封建社会的百科全书”。
2. 鲁迅《中国小说史略》评价：“自有《红楼梦》出来以后，传统的思想和写法都打破了。”
3. 与《三国演义》《水浒传》《西游记》并称“中国古典四大名著”，且一般认为《红楼梦》艺术成就最高。

#### 二、红学

1. 自清代以来，研究《红楼梦》形成专门学问，称为“红学”。
2. 主要研究流派包括：索隐派、考证派、评论派、文本细读派等。
3. 重要学者有胡适、俞平伯、周汝昌、冯其庸等。

#### 三、文化影响

1. 《红楼梦》对中国戏曲、绘画、影视、广告等文化领域影响深远。
2. 书中人物、典故、诗词进入日常生活语言。
3. 被译为多种外语，成为世界文学经典之一。
