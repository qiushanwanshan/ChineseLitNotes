南戏与《琵琶记》

第一节 南戏的形成与发展​

一、南戏的概念​

  1. 南戏，又称“戏文”，是宋元时期流行于南方（主要是浙江温州、福建等地）的戏曲形式。
  2. 因起源于温州，又称“温州杂剧”或“永嘉杂剧”。
  3. 南戏是中国戏曲由北方杂剧向明清传奇发展的重要过渡形式。

二、南戏的体制特点​

  1. 结构灵活：不限折数，可长可短，通常以“出”为单位。
  2. 角色分工：生、旦、净、丑、末等行当齐全。
  3. 演唱方式：不拘一人主唱，各角色均可演唱，形式更自由。
  4. 音乐基础：以南曲为主，曲调柔婉，与北曲刚健风格不同。
  5. 表演风格：更贴近南方民间生活，细腻委婉。

三、早期南戏作品​

  1. “宋元四大南戏”（或“荆刘拜杀”）：
    • 《荆钗记》：王十朋与钱玉莲的爱情故事。
    • 《刘知远白兔记》：刘知远与李三娘的故事。
    • 《拜月亭》：王瑞兰与蒋世隆的爱情故事（与关汉卿杂剧同名）。
    • 《杀狗记》：杨氏兄弟的家庭伦理故事。
  2. 这些作品多表现民间伦理、爱情婚姻、家庭纠纷等题材。

第二节 高明与《琵琶记》​

一、高明的生平​

  1. 高明，字则诚，号菜根道人，温州瑞安人，约活动于元末明初。
  2. 曾仕途沉浮，晚年归隐，潜心创作《琵琶记》。
  3. 《琵琶记》被尊为“南戏之祖”，对明清传奇发展影响巨大。

二、《琵琶记》剧情​

  1. 书生蔡伯喈新婚两月，奉父命赴京应试，考中状元。
  2. 牛丞相奉旨招他为婿，蔡伯喈辞婚、辞官均不被允许，被迫入赘牛府。
  3. 家乡遭遇饥荒，妻子赵五娘含辛茹苦赡养公婆。公婆双亡后，赵五娘剪发卖发、罗裙包土，安葬公婆，身背琵琶进京寻夫。
  4. 牛小姐贤德大度，得知真相后帮助蔡伯喈与赵五娘团聚。
  5. 最终一夫二妻团圆，蔡伯喈辞官守孝。

三、《琵琶记》的主题​

  1. 宣扬“子孝妻贤”的封建伦理，体现作者“不关风化体，纵好也徒然”的创作观。
  2. 同时真实反映了元代社会动荡、饥荒灾年、士人科举两难等现实问题。
  3. 赵五娘形象集中体现了古代劳动妇女的勤劳、坚忍、孝顺和自我牺牲精神。

四、艺术成就​

  1. 双线结构：一条线写蔡伯喈在京城的高中与富贵生活，一条线写赵五娘在家乡的苦难。两条线索对比鲜明，深化了悲剧意味。
  2. 人物塑造：赵五娘形象丰满感人，是中国古代戏曲中最具代表性的女性形象之一。
  3. 曲词本色：语言质朴自然，符合人物身份，如赵五娘唱词悲凉真切，牛小姐唱词文雅端庄。
  4. 音乐成就：对南曲声律进行了系统整理，为后世传奇提供了规范。

五、历史影响​

  1. 被誉为“南戏之祖”，标志着南戏由民间粗糙形态向文人精致化转变。
  2. 对明清传奇如《牡丹亭》《桃花扇》《长生殿》等在题材、结构、曲词方面均有深远影响。
  3. 明代戏曲理论家徐渭《南词叙录》对其评价甚高。
