### 第一节 《聊斋志异》

#### 一、作者与成书

1. **蒲松龄**（1640–1715），字留仙，号柳泉居士，山东淄川人。清代著名文学家。
2. 一生科举不利，长期在家乡坐馆教书，积累大量民间传说和自身见闻。
3. 《聊斋志异》是蒲松龄倾注毕生心血的文言短篇小说集，全书约 490 余篇。
4. 书名“聊斋”是蒲松龄书斋名，“志异”即记录奇异之事。

#### 二、主要内容

1. 小说以鬼狐花妖、神仙精怪故事为主，借虚幻世界反映现实社会。
2. 题材大致可分为：爱情故事、科举讽刺、官场批判、社会黑暗、家庭伦理、侠义公案等。

#### 三、主题思想

1. **批判科举制度**：如《叶生》《司文郎》《王子安》等篇，揭露科举对文人的摧残和考官的昏庸。
2. **歌颂爱情自由**：如《婴宁》《小翠》《连城》《聂小倩》等，写人与鬼狐之间的真挚爱情。
3. **讽刺社会黑暗**：如《促织》写官府逼迫百姓供奉蟋蟀，家破人亡；《席方平》写阴间司法腐败。
4. **赞美正直善良**：如《张不量》《赵城虎》等，歌颂普通人的善良和侠义。

#### 四、艺术特色

1. **“用传奇法，而以志怪”**：鲁迅评价其继承唐传奇手法，写志怪题材，艺术上达到新高度。
2. **花妖鬼狐人格化**：狐女、花仙、鬼魂等形象美丽善良、富有人情味。
3. **情节曲折离奇**：善于设置悬念、营造氛围，引人入胜。
4. **语言精炼典雅**：融合文言的简洁与口语的生动，兼具诗意与叙事性。
5. **结构短小精悍**：每篇独立成篇，结尾常附“异史氏曰”发表评论。

#### 五、代表作品赏析

1. **《聂小倩》**：女鬼聂小倩在宁采臣帮助下脱离妖魔控制，最终复活与宁采臣成婚，歌颂善良与爱情。
2. **《婴宁》**：狐女婴宁天真爱笑，象征自然人性，后被礼教环境改造，失去天性，带有悲剧意味。
3. **《促织》**：通过成名一家因捉蟋蟀而几近家破人亡的悲剧，批判封建统治的残酷。
4. **《司文郎》**：以盲僧凭气味评文，讽刺科举考官不辨好歹、埋没人才。

### 第二节 《儒林外史》

#### 一、作者与成书

1. **吴敬梓**（1701–1754），字敏轩，号粒民，安徽全椒人。清代小说家。
2. 出身科举世家，早年热衷功名，后看破科举，晚年穷困潦倒，寄居南京。
3. 《儒林外史》约创作于乾隆年间，是中国第一部长篇讽刺小说。
4. 通行本五十六回，以众多人物连缀成书，无单一中心主人公。

#### 二、主要内容

1. 小说以明清科举制度下的读书人生活为中心，描写形形色色儒林人物。
2. 上至翰林、进士，下至秀才、童生，乃至乡村塾师、市井文人，皆入书中。
3. 通过周进、范进、严监生、匡超人、杜少卿等人物，展现科举制度对人性的扭曲。

#### 三、主题思想

1. **批判科举制度**：揭露八股取士如何使读书人沉迷功名、丧失真才实学。
2. **讽刺封建礼教**：批判虚伪的道学先生和僵化的伦理道德。
3. **肯定真儒理想**：通过王冕、杜少卿、虞育德等正面人物，寄托作者对理想人格的向往。
4. **反思社会价值**：探讨功名富贵与人格独立、精神自由之间的关系。

#### 四、人物形象

1. **周进、范进**：老年得中，喜极而疯，是科举制度下读书人悲剧的典型。
2. **严监生**：吝啬鬼典型，临终因灯盏里两根灯草而不肯咽气，刻画入微。
3. **匡超人**：由淳朴少年堕落为虚伪钻营的文人，体现科举对人性的腐蚀。
4. **杜少卿**：蔑视功名、慷慨好义，是作者理想人格的化身。
5. **王冕**：开篇人物，才华横溢而不屑功名，作为全书理想标杆。

#### 五、艺术特色

1. **讽刺艺术成熟**：善于通过夸张、对比、白描等手法，揭露人物丑态而不显刻薄。
2. **结构独特**：全书无贯穿主人公，以人物串联故事，类似“连环短篇”结构。
3. **白描手法**：不事渲染，用简练笔墨刻画人物性格。
4. **语言洗练**：叙事冷静客观，讽刺含蓄深刻。
5. **现实主义的深化**：对明清社会士阶层的描写具有很高的史料价值。

#### 六、历史影响

1. 《儒林外史》开创中国长篇讽刺小说传统，直接影响晚清谴责小说（如《官场现形记》《二十年目睹之怪现状》）。
2. 鲁迅《中国小说史略》高度评价其讽刺艺术。
3. 被翻译为多种外文，在国际汉学界享有盛誉。
