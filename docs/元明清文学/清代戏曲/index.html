清代戏曲

第一节 清代戏曲的发展概况​

一、昆曲的鼎盛与衰落​

  1. 清初昆曲仍是主流戏曲，被称为“雅部”。
  2. 康熙、乾隆年间，昆曲达到鼎盛，宫廷与民间均盛行昆曲演出。
  3. 乾隆以后，昆曲逐渐走向僵化，被新兴的地方戏“花部”取代。
  4. 清代戏曲史称“花雅之争”，最终花部（京剧等）占据主流。

二、清代传奇的代表作家​

  1. 清初以李玉、李渔、洪昇、孔尚任为代表。
  2. 李玉创作“一人永占”（《一捧雪》《人兽关》《永团圆》《占花魁》）及《清忠谱》等。
  3. 李渔既是剧作家又是戏曲理论家，著有《笠翁十种曲》和《闲情偶寄》。

三、清代戏曲理论​

  1. 李渔《闲情偶寄》：
    • 系统论述戏曲创作与表演，包括“词曲部”“演习部”“声容部”等。
    • 提出“结构第一”“立主脑”“减头绪”“密针线”等编剧原则。
    • 重视戏曲的娱乐性和舞台性，对后世戏曲创作和表演影响深远。

第二节 洪昇与《长生殿》​

一、洪昇生平​

  1. 洪昇（1645–1704），字昉思，号稗畦，浙江钱塘人。清代著名戏曲家。
  2. 出身书香门第，早年有才名，但仕途坎坷，晚年因《长生殿》演出获罪，醉酒落水而亡。

二、《长生殿》剧情​

  1. 以唐玄宗李隆基与杨贵妃杨玉环的爱情故事为主线。
  2. 描写二人从相识、定情、宠爱到马嵬坡事变、生离死别，最终在月宫团圆。
  3. 全剧五十出，分上下两卷，上卷写乐极，下卷写悲来。

三、主题思想​

  1. 歌颂爱情：将李杨爱情理想化，超越帝王与妃子的身份，表现真挚情感。
  2. 政治批判：揭露唐玄宗耽于享乐、重用奸佞导致安史之乱，反思国家兴亡。
  3. 兴亡之感：通过安史之乱描写盛唐由盛转衰，寄托明清易代后的家国之思。

四、艺术特色​

  1. 结构宏大，双线交织：爱情线与政治线并行。
  2. 曲词清丽典雅，融合唐诗意境，如《惊变》《埋玉》《闻铃》等出尤佳。
  3. 音乐上严守格律，适合昆曲演唱。
  4. 人物塑造具有深度：杨贵妃既美艳多情，又带悲剧宿命感。

第三节 孔尚任与《桃花扇》​

一、孔尚任生平​

  1. 孔尚任（1648–1718），字聘之，号东塘，山东曲阜人。孔子第六十四代孙。
  2. 曾任国子监博士、户部主事等职，晚年罢官归乡。
  3. 历经十余年创作《桃花扇》，是清代传奇的又一高峰。

二、《桃花扇》剧情​

  1. 以明末复社文人侯方域与秦淮名妓李香君的爱情故事为线索。
  2. 通过二人的悲欢离合，展现南明弘光小朝廷的兴亡过程。
  3. 剧中穿插阮大铖、马士英、史可法等历史人物，真实再现明末政治风云。
  4. 最终侯方域出家，李香君入道，以悲剧结局表达兴亡之叹。

三、主题思想​

  1. 借离合之情，写兴亡之感：个人爱情与家国命运紧密相连。
  2. 批判南明腐败：揭露权奸误国、党争不断、将士离心。
  3. 反思历史教训：以明朝灭亡警示后人。
  4. 坚守民族气节：通过李香君、史可法等人物歌颂忠义。

四、艺术特色​

  1. 历史真实与艺术虚构结合：人物多实有其人，事件多据史实。
  2. 结构精巧：以桃花扇为贯穿全剧的道具和象征，串连剧情。
  3. 人物塑造鲜明：李香君坚贞刚烈，侯方域软弱动摇，阮大铖奸诈阴险。
  4. 曲词苍凉悲壮：充满历史沧桑感。
  5. 结局的悲剧性：男女主人公双双出家，打破传统大团圆模式。

第四节 清代戏曲的历史地位​

一、传奇的集大成​

  1. 《长生殿》《桃花扇》代表清代传奇最高成就，与明代《牡丹亭》《西厢记》并称中国戏曲经典。
  2. 它们在主题深度、历史意识、音乐格律等方面都达到很高水平。

二、戏曲理论系统化​

  1. 李渔《闲情偶寄》是中国古代最系统的戏曲理论著作。
  2. 对编剧、导演、表演、音乐、舞台美术等均有论述。

三、花雅之争与京剧形成​

  1. 乾隆五十五年（1790），四大徽班进京，徽调与汉调融合，逐步形成京剧。
  2. 京剧取代昆曲成为清代后期主流戏曲，开启中国戏曲新阶段。
